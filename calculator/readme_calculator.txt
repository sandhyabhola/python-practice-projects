# Calculator Project

## Overview

This is a menu-driven calculator built using Python. The project allows users to perform various mathematical operations and maintains a calculation history during program execution.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Modulus
* Power Calculation
* Root Calculation
* Input Validation
* Error Handling
* Calculation History
* Continue/Exit Option

## Concepts Practiced

### Python Fundamentals

* Functions
* Loops
* Conditional Statements
* Lists
* User Input
* String Formatting

### Exception Handling

* ValueError
* ZeroDivisionError

### Problem Solving

* Menu-driven application design
* User interaction handling
* History tracking

## How It Works

1. User selects an operation.
2. User enters the required numbers.
3. Program performs the calculation.
4. Result is displayed.
5. Result is saved in history.
6. User can view history.
7. User can continue or exit.

## Sample Operations

* 10 + 5 = 15
* 10 - 5 = 5
* 10 * 5 = 50
* 10 / 5 = 2.0
* 10 % 3 = 1
* 2 ^ 5 = 32
* 3rd root of 27 = 3
